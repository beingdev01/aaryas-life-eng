# Skill: writing a themed angle that is not generic spam

A themed angle maps one specific sponsor product or program onto one specific club
activity, so the ask reads as "this only makes sense for you". Generic asks
("we'd love to partner, we have 500 members") get deleted unread; a themed angle
gets a reply.

**Build it in three moves.**
1. One concrete thing our members do. Not "events" — name it: the monthly DSA
   contest, the live quiz platform, the certificate generator, the coding
   playground, a hackathon like SFIC/TechSprint, a workshop series.
2. The exact gap or fit for THIS sponsor. Their product removes a gap our members
   have, or their student program wants exactly the room we have.
3. The one, tier-appropriate ask. A named session with their branding, a listing,
   credits/swag *if their program covers them*, or a 15-minute call. One ask.

**Worked example (dev-tools, a testing company).**
"Our members ship web and mobile projects but almost nobody tests on anything but
their own laptop browser before a project goes live. Run one co-branded session on
cross-browser and real-device testing on a real member project; your branding on
the material and certificates, the session listed on https://codescriet.dev, and
members pointed at the free access your student page describes." Specific product,
real gap, one ask, no numbers invented.

**De-collision rule.** Keep a running list of which theme belongs to which company
(the last run notes it at the top of the dated file): database/ORM, Postgres
branching, API testing, product analytics, error reporting, CI/CD, auth, deploy,
AI coding assistants, mobile. A new prospect must take a theme not already pitched
so we never send the same pitch twice.

**Never do:** open with flattery, list member counts, ask for money in first touch,
or copy a template across companies. If the angle would read the same to any
sponsor, it is spam — rewrite it.
